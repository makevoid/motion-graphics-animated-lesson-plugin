# Curtain call, ending layouts and relevant credits

Read [the ending template](../assets/templates/ending/TEMPLATE.md) and inspect its editable SVG layout guides before designing the ending. `layouts.json` saves the format and region coordinates. Export project-local PNG guides only if a model needs image references; keep exact lettering in p5. Curtain stills, silent clips and archived frame images are omitted. Follow [assets to regenerate](cast-and-assets.md#assets-to-regenerate) and [ending image recipes](../assets/templates/ending/regeneration.md) before using selected replacements.

The reference rhythm is: last callback line → music stops → 2.0 s silent reaction with a restrained 4% push → tada + 1.0 s iris to black → velvet folds/closes, holds, opens → end card/parade → credits → final small joke. This is the default, adaptable to the brief. Never omit the ending simply because the lesson scenes are done.

Use locally regenerated `close.mp4` and `open.mp4` through `source:` clips with `key: green`. Render black behind the closing curtain; begin the end-card clock behind the opening curtain. The omitted originals had close motion approximately at clip 0.4–2.75 s and opening at 0.5–3.6 s; use a piecewise table mapping section time to clip time, measure the regenerated clips rather than assuming these landmarks, and clamp the endpoints. Only these silent theatrical motions may be retimed. Scale curtain toward 1.35 and fade for its fly-out. [Ending motion recipes](ending-motion.md) preserve the mapping, iris, loop anchoring and scrolling algorithms; adapt timing to the current narration.

Use the end-card, alternating animated-face credits, two-column crew blocks and final-callback layouts from the template. Regenerate the selected `face_prof`, `face_luca` and `run_luca` silent MP4s to supply professor/developer faces and the developer's curtain-call run. Credit only the selected roles. A final professor reaction or developer aside should pay off an earlier setup; do not inherit the source lesson's supporting cast or their gags.

At each join keep the card clock continuous. An optional 72-frame VHS rewind bridge follows this pattern: command/visual trigger → reverse b-roll → STOP → PLAY → flash into credit title. Use new-lesson frames and a topic-appropriate trigger, not the original commit hash. Match the flash intensity on both sides of the cut.

Music defaults: generate `intro` for the hook and `titles` for curtain/credits from the supplied prompts after production authorization, or reuse accepted project/local tracks. Stop the teaching bed on the final spoken joke; start titles with the curtain (`fade_in: 0.8`, no duck only while no speech), tape-stop/restart only if using the rewind, and stop again on the final callback. Reuse accepted music files unchanged; apply looping, fades and ducking to the mix, not the source assets.

Credits must describe this production. Save `docs/CREDITS.json` using [the credits data template](../assets/templates/credits.json). Include only characters that appear; voice mappings come from generated line metadata. Model versions, quality/resolution, music reuse and actual tooling come from manifests/config. Credit reused original media as reused, not newly generated. Optional tools such as Swift and sub-agents belong in credits only if used. Name actual people when known; do not inherit “makevoid” as producer or the source's eight-wave/29-job claim automatically. Keep jokes tied to this lesson's concept and cast (e.g. professor as “chalk continuity,” developer as “unexpected demo operator”), followed by a callback that pays off a setup.

If inserting the finale late: extend narration tail without moving words, shift every later section/cue/bed boundary, regenerate affected `gen:music` cuts, refresh `anim:prepare`, invalidate old-length plate/overlay caches and rerender moved sections. Compare word timestamps and final counts. Review last word, silence, iris midpoint/black, curtain folds/closed/reveal/fly-out, full end card, scroll entries and final held gag with audio.
