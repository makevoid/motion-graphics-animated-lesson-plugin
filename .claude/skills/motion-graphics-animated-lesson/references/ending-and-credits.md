# Curtain call, ending layouts and relevant credits

Read [the ending template](../assets/templates/ending/TEMPLATE.md) and inspect its PNG layout guides and original-frame examples before designing the ending. `layouts.json` saves the format and region coordinates; SVGs support edits. Supply the appropriate images as model references for new visual layers. Keep exact lettering in p5. Original curtain images and silent clips are in `assets/lesson/curtain/`.

The reference rhythm is: last callback line → music stops → 2.0 s silent reaction with a restrained 4% push → tada + 1.0 s iris to black → velvet folds/closes, holds, opens → end card/parade → credits → final small joke. This is the default, adaptable to the brief. Never omit the ending simply because the lesson scenes are done.

Use preserved `close.mp4` and `open.mp4` through `source:` clips with `key: green`. Render black behind the closing curtain; begin the end-card clock behind the opening curtain. Source close motion lies approximately at clip 0.4–2.75 s and opening at 0.5–3.6 s; use a piecewise table mapping section time to clip time, inspect the actual frames, and clamp the endpoints. Only these silent theatrical motions may be retimed. Scale curtain toward 1.35 and fade for its fly-out. `assets/lesson/examples/s09c/05_overlay.js` preserves the actual mapping/compositing code; adapt references, data and timing.

The iris code is in `examples/s09/05_overlay.js`. Source end-card, alternating animated-face credits, two-column crew blocks, readable eased scrolling and final callback are in `examples/s10/05_overlay.js`. The scripts contain the old topic, cast, paths and dates: extract the techniques and replace the content, rather than copying the whole lesson. The bundled `face_prof`, `face_luca` and `run_luca` silent MP4s can supply default faces/parade; optional cast needs its own prepared loops or reviewed still puppetry.

At each join keep the card clock continuous. The optional `examples/s09t/05_overlay.js` bridge is a 72-frame VHS rewind: command/visual trigger → reverse b-roll → STOP → PLAY → flash into credit title. Use new-lesson frames and a topic-appropriate trigger, not the original commit hash. Match the flash intensity on both sides of the cut.

Music defaults: original `intro.wav` for the hook and `titles.wav` for curtain/credits, reused without regeneration. Stop the teaching bed on the final spoken joke; start titles with the curtain (`fade_in: 0.8`, no duck only while no speech), tape-stop/restart only if using the rewind, and stop again on the final callback. Reuse the supplied music files unchanged; apply looping, fades and ducking to the mix, not the source assets.

Credits must describe this production. Save `docs/CREDITS.json` using [the credits data template](../assets/templates/credits.json). Include only characters that appear; voice mappings come from generated line metadata. Model versions, quality/resolution, music reuse and actual tooling come from manifests/config. Credit reused original media as reused, not newly generated. Optional tools such as Swift and sub-agents belong in credits only if used. Name actual people when known; do not inherit “makevoid” as producer or the source's eight-wave/29-job claim automatically. Keep jokes tied to this lesson's concept and cast (e.g. professor as “chalk continuity,” developer as “unexpected demo operator”), followed by a callback that pays off a setup.

If inserting the finale late: extend narration tail without moving words, shift every later section/cue/bed boundary, regenerate affected `gen:music` cuts, refresh `anim:prepare`, invalidate old-length plate/overlay caches and rerender moved sections. Compare word timestamps and final counts. Review last word, silence, iris midpoint/black, curtain folds/closed/reveal/fly-out, full end card, scroll entries and final held gag with audio.
