# 0.2.2 — GPT Image 2.6 Sunburst

Character generation, identity revisions and keyframe edits now use `openai/gpt-image-2.6/sunburst/text-to-image` and `openai/gpt-image-2.6/sunburst/edit`. Both adapters explicitly send `quality: "high"` and `reasoning_effort: "high"`. PNG output, one image per request and the 2752 × 1536 default size are retained; callers can still override request options.

The [generation schema](https://fal.ai/api/openapi/queue/openapi.json?endpoint_id=openai/gpt-image-2.6/sunburst/text-to-image) and [edit schema](https://fal.ai/api/openapi/queue/openapi.json?endpoint_id=openai/gpt-image-2.6/sunburst/edit) were checked on 2026-11-06. Rendering quality supports `auto`, `low`, `medium`, `high`, `xhigh` and `max`; reasoning effort independently supports `low`, `medium` and `high`. The edit endpoint requires `image_urls` and supports up to 16 references. Default image dimensions satisfy the generation schema's edge, pixel-count, aspect-ratio and multiple-of-16 constraints.

New projects use `Fal::Models::GptImage26` and `Fal::Models::GptImage26Edit`. Existing lesson projects contain their own runtime copy, so updating the plugin alone does not migrate them. When upgrading a copied runtime, update explicit model constants in `config/generations.rb` to the new class names. Existing generated media and receipts remain valid historical records.

Regression tests exercise the real queue client's submit/poll/result path with mocked HTTP for both endpoints, verify high/high defaults and reference forwarding, and check that explicit quality, reasoning and size overrides create distinct requests.

Validation on 2026-11-06: all 59 non-live examples passed, including media and Swift rendering, with the runtime's `.venv/bin` on `PATH` so subprocesses in temporary projects use the installed Python packages. One real generation and one real edit also passed through the updated adapters and fetched schemas, each returning a 2752 × 1536 PNG at high/high. Both images were visually inspected: the edit preserved the professor's appearance and book while changing his hand to a raised wave. Test images, queue receipts and credentials are excluded from the release. The broader paid audio/video E2E was not rerun for this image-model update.
